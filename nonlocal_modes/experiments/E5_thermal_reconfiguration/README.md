# E5 —— 热边界可重构调控（论文 Fig.3 / Fig.6）

**思想**：不改样品形状，而是让圆形样品的**边界温度**按 Θ cos n(θ−θ₀) 分布（实验上可用沿圆周排布的加热片/珀尔帖元件）。
热传导方程是线性的，样品内多出一个与光功率无关的调和折射率 Θ(r/R)^n cos n(θ−θ₀)：
各向异性强度 Θ 可连续调节、可反号、可旋转，还可以沿传播方向分段改变。

## E5a —— 稳态：r_s(Θ) 与取向翻转
```bash
cd nonlocal_modes/experiments/E5_thermal_reconfiguration
python e5a_boundary_heating.py --quick     # 约 5 分钟 ((3,2), (4,3) 两种情形, Θ≤1)
python e5a_boundary_heating.py             # 正式, 约 30-60 分钟, 六种 (n,m)
python e5a_boundary_heating.py --cases 3,2 --tag check32    # 只算一种情形 (复核用)
```
输出：`heating_n<n>_m<m>.csv`（每个 Θ：中心荷、卫星数、r_s 检测值/拟合值、第一颗卫星方位角）、`heating_rs.png`（r_s vs Θ 的 log-log 图与拟合斜率）、`heating_mode_*.png`。

预期（docs/theory.md 第 3.5 节）：
| (n, m) | 中心荷 | 卫星 | r_s ∝ Θ^s |
|---|---|---|---|
| (3, 2) | −1 | 3 | s = 1 |
| (4, 3) | −1 | 4 | s = 1/2 |
| (3, 3) | 0 | 3 | s = 1/3 |
| (5, 3) | −2 | 5 | s = 1 |
| (6, 4) | −2 | 6 | s = 1/2 |
| (2, 2) | 0 | 2 | s = 1/2（四极加热 → 可调“双涡旋”） |

* Θ 反号 → 卫星环整体转 π/n（看 `sat_angle` 列）；
* 每个 Θ 还记录 `P_outer`（r>R/2 的功率比例）与 `hybrid`（与边缘热点模式杂化，见 E5b 一节）；斜率只用 hybrid=False 的点拟合。
  (3,2) 在 Θ_max=4 附近预期出现杂化或延拓中断（日志 `param continuation stopped between ...`），这是物理现象，请记录其 Θ 值；
  hq 云端测试（h=0.1）：(3,2) 两个方向都停在 |Θ|≈3.8，斜率 1.008，Θ≥1 时卫星可直接分辨；`heating_mode_*.png` 画的是每个方向最后一个成功的点；
* 预实验（h=0.4/0.2）：(3,2) 拟合斜率 **1.004**；(4,3) 0.446（理论 0.5），Θ 反号卫星环转 45°；(6,4) 中心 −2、6 个卫星，r_s ∝ Θ^0.52；(5,3) 中心 −2 在 Θ ≥ 2 时出现。
* n=5、6 的嬗变规则主要靠本实验展示（多边形样品中太弱，见 E0d）。

```bash
python e5b_dynamic_control.py --quick      # 约 5 分钟

```

hq 档：h=0.1（R=10 圆盘），E5a 每种情形 19 个 Θ（与正式运行同一范围，公比 √2，单核约 2–5 h），E5b 传播到 ξ=600、dz=0.01（约 3–6 h）；Θ 延拓使用割线预测与更细的步长（细网格上卫星环外移被完全分辨，大步长难收敛）。
起点：C_3 加热（默认 Θ=3，U=15）下 m=2 的嬗变定态：中心 −1 + 3 个卫星，r≈0.43（h=0.2 时约 2h，h=0.1 时约 4h，可分辨；
Θ 太小则卫星落在亚网格，结论不可信）。日志中 `start state:` 一行会给出外围功率比例与外围奇点数；正式运行中出现 `WARNING` 说明起点不合格
（`--quick` 用 h=0.4，卫星必然未分辨，会打印 `satellite ring ... not resolved` 警告，属正常——quick 只检查程序能否运行）。

**为什么默认值从 Θ=4 改成 3（2026-10-10 诊断）**：边界处的折射率增量等于 Θ，样品边缘的 3 个“热点”附近有局域线性模式；
U=15 时 Θ ≳ 3.8，这些模式的传播常数接近涡旋的 b，涡旋与它们共振“杂化”——光功率漏到样品边缘（r>R/2 的比例从 0.7% 升到 2.4%），
尾部出现 3 个额外零点，解族沿 Θ 难以延拓（h=0.1 时 Θ=4 根本延拓不到）。Θ=3 时起点是干净的中心涡旋。

四种情形：
* `switch_off`：ξ > ξ_s 关断加热。预实验：卫星**不**收回中心，而是绕中心转动并呼吸，中心荷保持 −1（系统是保守的，没有弛豫）。
  Θ=3、ξ≤40 复核：关断前卫星静止于 r=0.43（h=0.2）/0.44（h=0.1）；关断后在 r=0.18–0.57 之间振荡并转动
  （h=0.1；h=0.2 时只能检测到 r>1.25h=0.25 的部分）。
  请记录长距离（ξ=300/600）下的转动角速度、呼吸周期，以及卫星是否最终与中心奇点湮灭/重组；
* `switch_C3_to_C4`：换成 C_4 图样 → m=2 在 C_4 中是 μ=n/2 简并情形，记录结构如何演化；
* `rotate_slow` / `rotate_fast`：图样以 Ω 旋转 → 慢转时卫星应绝热跟随（`tracks.png` 中方位角线性增长），快转时跟不上。

输出：`control_start_state.png`、`control_<case>_snapshots.png`、`control_<case>_tracks.csv/png`（奇点半径/方位角随 ξ）、`control_summary.csv`。

注意：横向热传导按稳态处理，要求图样沿 ξ 的变化远慢于横向热扩散；E5b 的旋转部分主要是拓扑动力学的理论展示，实验可行性需在论文中讨论。

## E5c —— 加热态的线性稳定性：(Θ, b) 平面的失稳窗口图（第二轮，2026-10）
**为什么要做**（Progress.md C8、开放问题 Q6、Q9）：
1. **机理的定量检验**：E3b 的假说是“C_n 边界把角向通道 L 与 L±n 耦合，Krein 符号相反的两支相遇处打开失稳窗口”。
   多边形的各向异性强度固定，无法检验；热边界 Θ cos nθ 的耦合强度 ∝ Θ 连续可调。Hamilton-Hopf 理论预言：加热诱导的新窗口
   出现在圆盘通道交叉点附近，**窗口宽度和最大增长率都 ∝ Θ**（双对数斜率 1）。
2. **E5b 起点是否稳定**（Θ=3、U=15、b≈2.27）：云端 h=0.4/0.2 的初步计算显示加热后的 m=2 态在 b≈2 处已经不稳定
   （h=0.2，b=2.0–2.6 全部不稳定；固定 U=15：Θ=1 时增长率 0.018（L=−3，κ=0，保持 C_3 对称），Θ=3 时 0.103（L=−1，κ=−1））；
   E5b 的 hq 轨迹在 ξ≈100–160 之后明显改变，
   与“种子放大的不稳定性”一致。需要 hq 确认，并据此重新解读 E5b 的长距离结果。

```bash
python e5c_heated_stability.py --quick                                   # 约 3 分钟 (3:2, Theta = 0, 2, h=0.4)
python e5c_heated_stability.py --hq --cases 3:2 --thetas 1.5 --job e5c_n3_m2_T1.5     # 一个 (情形, Theta)
python e5c_heated_stability.py --hq --table_only                         # 全部结束后重建汇总表与总图
```
情形 `n:m`（C_n 加热、拓扑荷 m）：3:2、4:2、3:1；Θ（hq）= 0、0.25、0.5、1、1.5、2、2.5、3；b 范围 m=2 为 0.05–3.0，m=1 为 0.05–1.5（R=10）。
每个 (情形, Θ)：在 b=2（m=1 为 1）处求圆盘解 → 固定 b 沿 Θ 延拓 → 沿 b 上下延拓；每 0.1 算一次谱（与 E3b 相同的低功率 shift 扫描），
交界处二分 4 次；m=2 时另在固定能流 U=15（E5b 的能流）处求解并算谱。Θ=0 即半径 10 的圆盘：由标度不变性，它的窗口应等于
E3 圆盘（ρ=8）的窗口乘 (8/10)² = 0.64（m=2：b_c ≈ 0.34）——这是自带的一致性检验。

输出：`e5c_n<n>_m<m>_T<Θ>_spectrum.csv`（每个 b 的增长率、L、κ、外围功率比例 P_outer）、`_row.json`、`_growth.png`、`_mode_b<值>.png`；
汇总 `e5c_summary.csv`（每个 (n,m,Θ) 一行，含 U=15 处的增长率 `growth_at_U_mark`）、`e5c_windows.csv`（每个窗口：边界、宽度、最大增长率、L/κ、
`induced`=是否为加热诱导的新窗口（与 Θ=0 的窗口不重叠）、`hybrid`=是否与边缘热点模式杂化）、`e5c_stability_map.png`
（上排：各情形 (Θ, b) 平面，方块=不稳定、颜色=增长率，虚线=U=15 的路径，星号=E5b 起点；下排：诱导窗口的最大增长率与宽度 vs Θ，斜率 1 参考线）。

**判读**：Θ=0 的窗口与 E3 圆盘按 0.64 缩放一致；小 Θ 时诱导窗口的宽度、增长率 ∝ Θ（斜率 1）→ 支持 Krein 碰撞机理；
若 Θ=3、U=15 不稳定，Progress.md 中把 E5b 的长距离结论改为“ξ ≲ ln(1/种子)/(2γ) 以内有效”。

**耗时（hq 单核，实测）**：每个 (情形, Θ) 2–7 h。

**第二轮结果（2026-10-12，详见 Progress.md C10、C13）**：Θ=0 的窗口上端 0.319–0.325 = 圆盘 ρ=8 的 0.494–0.500 × 0.64（标度不变性 ✓）；

## E5b（第四轮）—— Ω 扫描：临界跟随角速度与旋转方向的不对称
`--omegas` 列出角速度（负值 = 与涡旋自由共转反向），每个 Ω 一个情形 `rotate_Om<±Ω>`；`--ramp 100` 让角速度在 ξ≤100 内线性升起
（测稳态旋转的临界值，避免突然启动激发的振荡）；`--cases none` 不跑基本情形；`--zmax 600`。每个情形写 `<前缀><情形>_row.json`，
`--table_only` 由全部 row.json 汇总成 `control_runs.csv`，**并用轨迹/时间序列 CSV 按当前定义重算跟随指标**（旧运行也得到新定义）。

**跟随指标（2026-10-13 第四轮分析后的稳健定义，`following_metrics`）**：
* `rho` —— 斜坡之后、核心改变之前，卫星对取向（只用最内层 n 个 +1 卫星，展开、不折回）转过的角度 / 图样转过的角度（锁定 = 1）；
* `xi_slip` —— 展开的滞后 |Φ − Φ0 − θ_pattern| 第一次超过 π/n 的 ξ（相位滑移；旧定义把滞后折回 (−π/2, π/2]，滑移被藏起来）；
* `xi_core_change` —— 核心区 r < 1.5（约 0.65 倍亮环半径）内奇点集合第一次改变的 ξ；
* `locked` —— |rho − 1| < 2%、无相位滑移、无核心改变；`xi_c2` —— C_n 非 μ 权重第一次超过 1e-3 的 ξ（对称性破缺）；
* `xi_any_change` —— 原 `xi_lock_lost`（1.5 倍亮环半径内奇点集合第一次改变）：常被外围暗区短暂进出的反涡旋对触发，
  也漏掉不改变奇点数的滑移（Θ=0.25、Ω=0.12/0.14），**只作参考**；
* `lag_mean/lag_max`（展开的滞后）、`r2_ratio`（斜坡之后到核心改变为止 r_sat² 的平均 / 起点）、`r_sat_min/max`、`corotation_rate`（关断情形）。
稳健性：把核心改变换成拓扑判据（反涡旋进入 r < 1.5，或 +1 涡旋被甩出 r > 1.75–2.3），52 个 Ω 扫描的 locked 分类一个都不变（第四轮分析）。
```bash
python e5b_dynamic_control.py --hq --n 2 --Theta 1 --cases none --omegas 0.04 --ramp 100 --zmax 600 --tag hq_omega --job n2_T1_Om+0.04
python e5b_dynamic_control.py --hq --tag hq_omega --table_only        # 汇总
```
quick（h=0.4，ξ=40，约 1 min）：`--quick --n 2 --Theta 0.5 --cases switch_off --omegas 0.1 -0.1 --ramp 10` 已跑通
（正向 r2_ratio=3.1、反向 0.70：同向旋转使间距变大、反向变小，与受迫振子图像的符号一致）。
**预期**（theory.md §5.1）：正向 Ω 有两个共振——一阶 ω_{−2}/2 ≈ 0.13–0.15（转动/分裂模）与二阶 ω_{−4}/4 ≈ 0.023–0.030（L=−4 模，驱动 ∝ Θ²，
Θ 大时可能先失锁：第三轮 Θ=1 在 0.05 失锁）；反向在扫描范围内都跟随；r2_ratio ≈ ω_{−2}/(ω_{−2} − 2Ω)。单核每个任务约 0.5 h。

**第四轮结果（2026-10-13，hq_omega，52 个；Progress.md C10；图 `analysis/a7_twin_vortex.py` (d)(e)）**：锁定区间 Θ=0.25：−0.2…0.10
（0.12/0.14 相位滑移，ρ=0.80/0.73）；Θ=0.5：−0.2…0.06，但 0.03 失锁（ξ=546 滑移，二阶共振 ω_{−4}/4=0.028）、≥0.08 失锁；
Θ=0.75：−0.1…0.01（−0.2 滑移）；Θ=1：−0.05…0.01（−0.1、−0.2 失锁）。锁定时 r2_ratio 与 ω_{−2}/(ω_{−2} − 2Ω)（ω 由 E5d 给出，无可调参数）
在 |Ω| ≤ 0.1、离开二阶共振处偏差 ≤ 4%（Θ=0.25、0.5），Θ=0.75/1 为 5%/15%（Ω=0.01，靠近二阶共振）；Ω=−0.2 处 +20%。
同向旋转的失锁对应两个共振（一阶的舌宽 ∝ Θ、二阶 ∝ Θ²）；反向旋转在 Θ ≥ 0.75 的失锁没有简单的频率判据 → E5e。
失锁距离对发射协议与网格敏感（Θ=1、Ω=0.05：突然启动 h=0.1/0.075 为 164/316，斜坡启动 93–102），只用“是否锁定”。

## E5d（第四轮）—— 双涡旋的低频 Bogoliubov 谱 vs Θ（Ω 扫描的理论输入）
`python e5d_twin_modes.py --hq --job e5d_n2`（默认四极加热、m=2、U=15、Θ=0–1.5 共 10 个；单核约 0.5–1 h；quick 约 1 min 已跑通）。
固定能流 U 的加热态沿 Θ 延拓，每个 Θ 求 Im λ ≤ 0.62 的本征值，按 L、Krein 符号分类（`e5d_n2_m2_U15_modes.csv/png`）；
`e5d_n2_m2_U15_summary.csv` 给出 ω_{−2}（L=−2、Krein + 的最低支 = 双涡旋整体转动/分裂模）与预言的临界角速度 Ω_c = ω_{−2}/2，
以及二阶共振 ω_{−4}/4。云端 hq 预算（2026-10-13）：ω_{−2} = 0.2523/0.2558/0.2657/0.2808（Θ=0/0.25/0.5/0.75），即 Ω_c 预言 0.126–0.140；
ω_{−4}/4 ≈ 0.030/0.029/0.028/0.026；另有一支破坏 C_2 的 Krein − 模（κ=1，双涡旋整体平移）随 Θ 变软 0.154/0.137/0.117/0.093/0.060，
ω² 严格线性 → Θ_c = 1.18，Θ=1.2 时已失稳（实本征值 0.022）：双涡旋稳定上限是破坏 C_2 的叉式分岔（Progress.md C10）。

**第四轮结果与修正（2026-10-13）**：hq 正式数据 Θ_c = 1.176（ω_odd² = 0.0238 − 0.0202 Θ）；E5c (2:2) Θ=1.2/1.3/1.5 的增长率
0.02165/0.04984/0.08070 落在同一条直线外推上。**ω_{−2} 的追踪**：Θ ≥ 1 时转动/分裂模的 u 主谐波从 e^{0iθ} 变成 e^{−2iθ}，标签由 L=−2 变成 −4，
按标签选会跳到另一支（0.825，师弟第四轮自查发现）；`summarize` 改为从 Θ=0 的 L=−2 支出发按频率连续性追踪（同一 Krein 符号、κ=0、
相邻 Θ 频差 < 0.05），得到 ω_rot = 0.2523/0.2532/0.2558/0.2657/0.2808/0.3000/0.3087/0.3179/0.3276/0.3489（Θ=0–1.5）。

* `--fields_only --thetas 0 0.25 0.5 0.75 1 1.2`：只求各 Θ 的定态，导出 |x|,|y| ≤ 4 的场 `fields/e5d_n2_m2_U15_T<Θ>.npz`
  （单精度，每个约 50 kB），供 Fig.6 场图（`analysis/a7_twin_vortex.py --fields_only` → `twin_vortex_fields.png`）；几分钟。

## E5e（第五轮）—— 旋转坐标系中的同步定态与线性稳定性：跟随相图的理论边界
`nlmodes` 新增旋转坐标系（`model.rotation = Ω`：定态方程多一项 −iΩ∂_θ w，牛顿雅可比与稳定性算子同步加上；角向导数用四阶中心差分、严格反对称，
哈密顿结构不变；单元测试：圆盘涡旋 b → b + mΩ，角向通道 L 的本征值 λ → λ + iLΩ，32/32 通过）。
`e5e_rotating_frame.py` 对每个 Θ 先求静态双涡旋（U=15），再沿 Ω 正反两个方向延拓“与图样同步转动”的定态（Ω 网格 0.005，失败时步长减半），
每隔 `--spec_every` 个网格点求 Im λ ≤ 0.62 的低频谱，并在稳定性改变的相邻两点之间补算全部网格点（边界分辨率 0.005）。
* 定态存在且稳定 ⇔ 缓慢加速的图样可以锁定跟随；延拓停止（折返）或出现增长率 > 1e-5 的模给出理论边界，与 E5b 的 52 个传播结果对照；
* 被加热驱动的模（κ=0）在旋转系中的频率 ω_L − LΩ 过零时受迫响应发散，同步定态在共振前折返（hq：Θ=0.5 的分支在 Ω≈0.021 折返，
  线性预言的二阶共振在 0.028——软化型非线性把折返点提前）。延拓失败时在 `--max_jump`（0.03）与其一半处由远到近直接求解（初值取本段起点与最后一个解，
  三种全局化策略），找到共振另一侧的解后**先往回延拓**（步长 Δ/2、不超过 0.005，最多越过近侧折返点 0.03；若与本段已有的点重合，说明之前的失败只是数值上的，不记间隙），
  再往前延拓。两段在 Ω 上重叠 = 两支同步定态并存（Duffing 型 S 形响应曲线：quick 中反相支往回延伸的部分是 L=−4 实本征值的鞍点，
  只在折返点附近两支同时稳定 = 双稳）；不重叠 = 间隙。汇总表给出 `resonance_gaps` 与 `branch_overlaps`，稳定 / 失稳区间带段号 `lo..hi[段]`。共振另一侧的稳定段就是 E5b 中“0.03 失锁、0.04–0.06 又锁定”的理论对应；
* 定态两个 +1 涡旋的半间距直接给出 r_s²(Ω)/r_s²(0)，检验 ω_rot/(ω_rot − 2Ω)；亮环处谐波比 c_{m−n}/c_m、c_{m−2n}/c_m 记录一阶 / 二阶受迫响应；
* 反向旋转：quick（h=0.4）中 Θ=0.5 在 Ω≈−0.10 到 −0.18 出现 κ=±1（破坏 C_2 的平移模）的实失稳——E5b 中 Θ ≥ 0.75 反向失锁的候选机理（hq 待定）。
* **云端 hq 点检（2026-10-13，Θ=0.5，Ω=−0.01…0.045）**：同相双涡旋支在 Ω≈0.021 折返；共振另一侧的一支从 0.045 往回延伸到 −0.009，
  其 b(Ω) 关于 Ω=0 对称（b=2.3485、角动量 0）——在 Ω=0 处是另一个实的驻波型（四极）定态，转动时获得角动量，Ω≳0.03 时成为双涡旋型。
  这一支上找不到两个 +1 涡旋的点 r_s 记为 nan，`a7` 只把有涡旋对的稳定段画成可锁定。同相支 Ω ≤ 0.015 稳定、0.02 失稳（1.13e-2）、
  折返点 0.0209 为 1.59e-2（绝热锁定上限 ≈ 0.0175）；同步定态的 r_s² 比值在 Ω=0.005/0.01 为 1.052/1.112，与 E5b 传播实测 1.049/1.110 相差 ≤ 0.3%。
  另一支 Ω ≤ 0.025 强烈失稳（增长率 0.19→0.035，Ω ≤ 0 时没有涡旋对），Ω=0.03 起稳定 → 0.0175 < Ω < 0.0275 内没有稳定的同步双涡旋（二阶共振舌），
  与 E5b 中 Θ=0.5 “0.03 失锁、0.04–0.06 锁定”一致。耗时：牛顿每次迭代约 15 s，延拓 60 min，
  每个谱点实测 3–6 min（旧的 11 个 shift；现用 3 个 shift，按 h=0.2 实测的 3 倍加速推算约 1.5–2 min），内存 2.2 GB。
```bash
python e5e_rotating_frame.py --quick                                  # 约 2 min (h=0.4, 只检查流程)
python e5e_rotating_frame.py --hq --thetas 0.5 --job T0.5              # 单核约 3-4 h (超算按 Θ 拆分, 9 个 Θ)
python e5e_rotating_frame.py --hq --table_only --job summary          # 汇总 e5e_n2_m2_U15_summary.csv
```
输出：`e5e_n2_m2_U15_T<Θ>_branch.csv`（每个 Ω：分段、b、r_s、r2_ratio、谐波比、增长率与最不稳定模）、`_modes.csv`（全部低频本征值）、
`.png`（谱、增长率、r2_ratio 对理论），`e5e_n2_m2_U15_summary.csv`（每个 Θ 的锁定区间及其原因、稳定 / 失稳区间、共振间隙、r2 对理论的偏差）。
