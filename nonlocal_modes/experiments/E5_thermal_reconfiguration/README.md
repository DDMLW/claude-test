# E5 —— 热边界可重构调控（论文 Fig.3 / Fig.6）

**思想**：不改样品形状，而是让圆形样品的**边界温度**按 Θ cos n(θ−θ₀) 分布（实验上可用沿圆周排布的加热片/珀尔帖元件）。
热传导方程是线性的，样品内多出一个与光功率无关的调和折射率 Θ(r/R)^n cos n(θ−θ₀)：
各向异性强度 Θ 可连续调节、可反号、可旋转，还可以沿传播方向分段改变。

## E5a —— 稳态：r_s(Θ) 与取向翻转
```bash
cd nonlocal_modes/experiments/E5_thermal_reconfiguration
python e5a_boundary_heating.py --quick     # 约 5 分钟 ((3,2), (4,3) 两种情形, Θ≤1)
python e5a_boundary_heating.py             # 正式, 约 30-60 分钟, 六种 (n,m)
```
输出：`heating_n<n>_m<m>.csv`（每个 Θ：中心荷、卫星数、r_s 检测值/拟合值、第一颗卫星方位角）、`heating_rs.png`（r_s vs Θ 的 log-log 图与拟合斜率）、`heating_mode_*.png`。

预期（docs/theory.md 第 3.5 节）：
| (n, m) | 中心荷 | 卫星 | r_s ∝ Θ^s |
|---|---|---|---|
| (3, 2) | −1 | 3 | s = 1 |
| (4, 3) | −1 | 4 | s = 1/2 |
| (3, 3) | 0 | 3 | s = 1/3 |
| (5, 3) | −2 | 5 | s = 1 |
| (6, 4) | −2 | 6 | s = 1/2 |
| (2, 2) | 0 | 2 | s = 1/2（四极加热 → 可调“双涡旋”） |

* Θ 反号 → 卫星环整体转 π/n（看 `sat_angle` 列）；
* 每个 Θ 还记录 `P_outer`（r>R/2 的功率比例）与 `hybrid`（与边缘热点模式杂化，见 E5b 一节）；斜率只用 hybrid=False 的点拟合。
  (3,2) 在 Θ_max=4 附近预期出现杂化或延拓中断（日志 `param continuation stopped between ...`），这是物理现象，请记录其 Θ 值；
* 预实验（h=0.4/0.2）：(3,2) 拟合斜率 **1.004**；(4,3) 0.446（理论 0.5），Θ 反号卫星环转 45°；(6,4) 中心 −2、6 个卫星，r_s ∝ Θ^0.52；(5,3) 中心 −2 在 Θ ≥ 2 时出现。
* n=5、6 的嬗变规则主要靠本实验展示（多边形样品中太弱，见 E0d）。

## E5b —— 动态控制：关断、切换、旋转
```bash
python e5b_dynamic_control.py --quick      # 约 5 分钟
python e5b_dynamic_control.py              # 正式, 约 1-2 小时 (xi 到 300)
python e5b_dynamic_control.py --Theta 2.5 --tag T25  # 较弱的加热 (默认 Theta=3; U=15 时不要超过 3.5, 见下)
```
**高精度（论文数据）**：在上面任一正式命令后加 `--hq`（结果写入 `hq/`），或在超算上用 [`../hpc/`](../hpc/README.md) 一次性拆分提交全部实验（推荐）。
hq 档：h=0.1（R=10 圆盘），E5a 每种情形 19 个 Θ（与正式运行同一范围，公比 √2，单核约 2–5 h），E5b 传播到 ξ=600、dz=0.01（约 3–6 h）；Θ 延拓使用割线预测与更细的步长（细网格上卫星环外移被完全分辨，大步长难收敛）。
起点：C_3 加热（默认 Θ=3，U=15）下 m=2 的嬗变定态：中心 −1 + 3 个卫星，r≈0.43（h=0.2 时约 2h，h=0.1 时约 4h，可分辨；
Θ 太小则卫星落在亚网格，结论不可信）。日志中 `start state:` 一行会给出外围功率比例与外围奇点数；正式运行中出现 `WARNING` 说明起点不合格
（`--quick` 用 h=0.4，卫星必然未分辨，会打印 `satellite ring ... not resolved` 警告，属正常——quick 只检查程序能否运行）。

**为什么默认值从 Θ=4 改成 3（2026-10-10 诊断）**：边界处的折射率增量等于 Θ，样品边缘的 3 个“热点”附近有局域线性模式；
U=15 时 Θ ≳ 3.8，这些模式的传播常数接近涡旋的 b，涡旋与它们共振“杂化”——光功率漏到样品边缘（r>R/2 的比例从 0.7% 升到 2.4%），
尾部出现 3 个额外零点，解族沿 Θ 难以延拓（h=0.1 时 Θ=4 根本延拓不到）。Θ=3 时起点是干净的中心涡旋。

四种情形：
* `switch_off`：ξ > ξ_s 关断加热。预实验：卫星**不**收回中心，而是绕中心转动并呼吸，中心荷保持 −1（系统是保守的，没有弛豫）。
  Θ=3、ξ≤40 复核：关断前卫星静止于 r=0.43（h=0.2）/0.44（h=0.1）；关断后在 r=0.18–0.57 之间振荡并转动
  （h=0.1；h=0.2 时只能检测到 r>1.25h=0.25 的部分）。
  请记录长距离（ξ=300/600）下的转动角速度、呼吸周期，以及卫星是否最终与中心奇点湮灭/重组；
* `switch_C3_to_C4`：换成 C_4 图样 → m=2 在 C_4 中是 μ=n/2 简并情形，记录结构如何演化；
* `rotate_slow` / `rotate_fast`：图样以 Ω 旋转 → 慢转时卫星应绝热跟随（`tracks.png` 中方位角线性增长），快转时跟不上。

输出：`control_start_state.png`、`control_<case>_snapshots.png`、`control_<case>_tracks.csv/png`（奇点半径/方位角随 ξ）、`control_summary.csv`。

注意：横向热传导按稳态处理，要求图样沿 ξ 的变化远慢于横向热扩散；E5b 的旋转部分主要是拓扑动力学的理论展示，实验可行性需在论文中讨论。
