# 研究方案：非局域非线性材料中特殊模态的设计

## 题目

**中文**：边界对称性主导的非局域涡旋孤子拓扑荷嬗变——从对称性传递定律到热边界可重构调控

**英文（暂定）**：*Boundary-symmetry design of vortex topology in nonlocal nonlinear media: symmetry transfer, topological-charge transmutation and thermally reconfigurable control*

> 一句话概括：**材料是完全均匀的，离散旋转对称性只存在于样品的边界上；无限程的热非局域响应把边界的对称性“搬运”到光束感受到的折射率中，从而按群论规则重排涡旋孤子的相位奇点。** 改变样品截面形状或边界温度分布，就能“设计”涡旋的拓扑结构。

---

## 1. 选题依据

### 1.1 已有基础（导师及合作者的工作）
* 热非局域介质中折射率由热传导方程决定，响应范围是整个样品，样品边界条件强烈影响光束（Rotschild et al., PRL 95, 213904 (2005)；Alfassi et al., PRL 98, 213901 (2007)、OL 32, 154 (2007)）。
* **表面偶极与涡旋**：绝热界面附近存在稳定的表面偶极、非正则表面涡旋及涡旋束缚态（Ye, Kartashov, Torner, PRA 2008；本项目 E0c 复现）。
* **双涡旋孤子**：矩形截面样品中，高阶涡旋不再是单个多重荷奇点，而是 m 个分离的单位奇点嵌在一个椭圆光束中；m=2 稳定，m≥3 不稳定（Ye, Kartashov, Hu, Torner, OL 35, 628 (2010)；本项目 E0b 复现）。
* 圆柱形热样品中 m≤2 的环形涡旋稳定（Kartashov, Vysloukh, Torner, Opt. Express 15, 9378 (2007)）。

### 1.2 相关领域进展
* **涡旋嬗变 (vortex transmutation)**：具有 C_n 离散旋转对称性的系统中角动量不守恒，守恒的是角赝动量 μ = m mod n，涡旋荷会按规则改变（Ferrando et al., PRL 95, 123901 (2005)；García-March et al., PRA 79, 053820 (2009)）。已在光子晶格、光子晶体光纤、几何超表面、多边形透镜中研究或观测。
* Kartashov (Chaos Solitons Fractals 175 (2023), arXiv:2309.04883)：环形波导阵列中可调离散旋转对称性下高阶涡旋分裂为单位奇点。
* 2025 年 Int. J. Theor. Phys. 有一篇正七边形热介质中**孤子轨道进动**的工作（只研究基模孤子的运动，不涉及涡旋拓扑）。

### 1.3 空白（本课题要回答的问题）
上述嬗变研究都依赖**线性的离散势**（晶格、波导阵列、光纤结构）。在**均匀**的非局域材料中，对称性的唯一来源是边界，目前：
1. 没有“边界对称性如何进入非线性响应”的定量定律；
2. 导师 2010 年的双涡旋只是 C_2（矩形）一个特例，缺少统一框架：为什么沿短轴排列？为什么 m 个奇点？存在阈值的条件是什么？
3. C_3、C_4、C_5、C_6 截面中涡旋的奇点结构、标度律、稳定性都没有人系统研究；
4. 没有利用边界温度（而不是形状）**主动、可重构**地设计涡旋拓扑的方案。

## 2. 核心科学问题
1. **对称性传递**：边界的 C_n 对称性以怎样的定量形式进入均匀介质的非线性折射率？
2. **选择定则**：电荷 m 的涡旋孤子在 C_n 样品中允许/必然具有怎样的奇点结构（中心荷、卫星环数目与半径）？何时存在功率阈值？
3. **稳定性**：嬗变后的“特殊模态”哪些稳定？边界对称性能否改变高阶涡旋的稳定性？
4. **可观测与可调控**：实验上用标准 LG 光束能否观察到嬗变？能否用边界温度连续、可逆、动态地改变拓扑结构？

## 3. 预期创新点（括号内为已完成的低分辨率预实验证据，正式结论以师弟的高分辨率结果为准）

1. **对称性传递定律（解析、普适）**：正 n 边形样品（保角半径 ρ）中心处任意 C_n 对称光束（总能流 U）产生的折射率，其最低阶各向异性项为
   δn = U/(π n(n+1)) · (r/ρ)^n cos nθ。系数与光束形状无关，只取决于 U 和 ρ。
   （预实验：n=3,5,6 数值/理论 = 1.0000，误差 <1e-4；对高斯、环形光束普适；对 U 线性。）
2. **保角半径普适性**：保角半径相同的任意正多边形与圆盘，各向同性热响应相同（只差 O((r/ρ)^n) 的各向异性）。
   （预实验：ρ=8 的三角形、正方形、五边形、六边形和圆盘中，m=0、1 解族的 U(b) 四位有效数字重合。）
3. **角赝动量选择定则 + “牛顿多边形”规则**：解只含角谐波 l = m − jn，振幅 ∝ ε^j；中心荷 v 取 |l| 最小者；卫星以 C_n 对称环分布，环半径 r_s ∝ ε^s，其中 s 由点集 (|l|, j) 的下凸包给出。ε ∝ U/ρ^n（形状）或 ε ∝ Θ/R^n（边界加热）。高阶涡旋对微小各向异性“超敏感”（s = 1/(|m|−|v|) 可以很小）。导师的双涡旋是 n=2 的特例（v=0，s=1/2）。n | 2m 时 +m 与 −m 直接耦合，预期存在存在阈值。
   （预实验：三角形中 m=2 → 中心 −1 + 三个 +1 卫星；正方形中 m=3 → 中心 −1 + 四个 +1 卫星；矩形 m=2,3 与导师 2010 年结果一致。r_s ∝ ρ^{−3}，(n,m)=(3,2) 拟合斜率 −3.009（理论 −3）；加热 r_s ∝ Θ^{1.004}（理论 1）。）
4. **稳定性图谱**：嬗变态的线性稳定性谱 + 加噪声传播。
   （预实验：三角形中嬗变后的 m=2 态在 b∈[0.5, 3.5] 线性稳定；m=3 振荡不稳定，增长率 0.06–0.13。完整图谱待正式计算——这是可能出现重要发现的部分。）
5. **动态嬗变（可实验验证的预言）**：标准 LG 涡旋射入多边形截面的均匀热样品（如铅玻璃），中心奇点在传播中自发嬗变（例如三角形中 +2 → −1）；C_n 不可约表示权重严格守恒；干涉图中可直接读出。
   （预实验：三角形 m=2 末态中心荷 −1，正方形 m=3 末态 −1，μ 权重漂移 ~1e-5。）
6. **热边界可重构调控**：边界温度多极图样产生与功率无关的 C_n 各向异性；反号使卫星环转动 π/n；关断加热可使嬗变可逆；沿传播方向旋转图样可使卫星绕转（奇点世界线成螺旋/辫子）。
   （预实验：C_4 加热下 Θ 反号卫星环转 45°；关断加热后中心荷由 −1 恢复为 +2。）

## 4. 理论框架（详见 docs/theory.md）
* 模型与导师论文完全相同：i∂_ξq = −½Δq − nq，Δn = −|q|²，边界 n = q = 0（或绝热/加热边界）。
* 用保角映射 f: Ω → 单位圆 写出 Dirichlet 格林函数 G = (1/2π) ln|(1 − f(z)f̄(z'))/(f(z) − f(z'))|，正 n 边形用 Schwarz–Christoffel 映射展开 f(z) = (z/ρ)[1 − 2/(n(n+1)) (z/ρ)^n + …]，即得对称性传递定律与保角半径普适性。
* C_n 群表示论给出角赝动量守恒与中心荷；把边界各向异性当微扰得到谐波振幅 ∝ ε^j，再用下凸包（牛顿多边形）确定卫星环与标度指数。
* 边界加热：调和多极 h = Θ(r/R)^n cos nθ（极值原理：自身不能导引光，只能与自陷效应共同作用）。

## 5. 数值方法（详见 docs/numerics.md）
* 格心笛卡尔网格 + 各向同性九点格式（把网格自身的 C_4 各向异性压到 O(h⁴)，这对本课题至关重要）+ Gibou 对称二阶边界格式（真实多边形/圆边界，热响应误差 O(h²)）。
* 定态：牛顿迭代（折射率作为附加未知量的稀疏增广雅可比，钉相位，三种全局化策略自动切换）+ 参数延拓（b、U、样品尺寸 ρ、边界温度 Θ）。
* 稳定性：全样品稀疏 shift-invert Arnoldi（沿虚轴扫描 shift），小问题用稠密法交叉检验。
* 传播：Crank–Nicolson + Strang 分步，严格保能流（机器精度）。
* 诊断：方格相位绕数（单位奇点）+ 多点圆周绕数 W(r)（中心多重荷，避免混叠）+ 角谐波拟合（亚网格嬗变半径）+ C_n 不可约表示投影。
* 可靠性：E0 系列（解析解、导师两篇论文的复现、网格收敛、网格假象底线、样品旋转检验）。
