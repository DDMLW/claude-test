# 数值方法说明与已知陷阱

本文档说明 `nlmodes/` 中每个数值环节的做法、理由与已经踩过的坑。写论文 Methods / Supplement 时可直接参考。

## 1. 网格与离散
* **格心网格**：节点 $x_i=(i+\tfrac12)h$，关于原点对称，原点和坐标轴都不是网格点/网格线。
  对称解的中心奇点、以及落在镜面对称轴上的卫星奇点都落在小方格内部，避免“奇点压在网格点上”导致相位无定义。
* **光场 Laplace 算子：各向同性九点格式** $L_9=\tfrac23L_++\tfrac13L_\times$。五点格式的截断误差含
  $\tfrac{h^2}{12}(\partial_x^4+\partial_y^4)$，即网格自带 C_4 对称的人为各向异性；本课题研究的恰是微弱的 C_n 各向异性，
  五点格式下网格效应会冒充物理效应（E0a 第 4 项：圆盘中 m=2 涡旋的人为 $|c_{-2}/c_2|$，九点格式比五点格式小 60–360 倍）。
* **热传导算子**：同样用九点格式，边界用 **Gibou–Fedkiw–Cheng–Kang (J. Comput. Phys. 176, 205 (2002)) 对称二阶格式**：
  沿每条“介质–热沉”边用水平集线性插值求真实边界位置 $\theta h$，只修改对角元和右端项，矩阵保持对称。
  阶梯近似会产生 $O(h)$ 的虚假偶极/四极分量（预实验中达到物理 C_3 分量的 10%），Gibou 格式把它降到 $O(h^2)$。
  E1a：对称性传递系数数值/理论 = 1.0000。
* **绝热界面**（PRA 2008 几何）：边上零热流；格心网格使界面 x=0 恰在两列节点正中。
* 所有算子按“边”组装，矩阵严格对称 → 线性稳定性谱保持哈密顿对称，不产生虚假增长率。

## 2. 定态：牛顿迭代
* 未知量 $(w_r, w_i, n_t)$，雅可比为稀疏 3×3 分块（见 `newton.py` 文件头），SuperLU 直接分解。每步后用 $n_t=G[|w|^2]$ 精确更新折射率。
* 复数解的 U(1) 相位不变性：把 |w| 最大点的虚部钉为 0；由 Noether 恒等式，被替换的方程在收敛时自动满足。
  线搜索的价值函数必须去掉这个被钉的方程（否则牛顿方向不是下降方向）。
* **全局化**：激发态（涡旋）的牛顿收敛域很小，冷启动时 Armijo 线搜索、纯牛顿、非单调线搜索三种策略各有成败（预实验统计），
  `solve_robust` 依次尝试；15 步内残差未降 100 倍即判为停滞以节省时间。
* **延拓**：沿 b、U（定功率模式，加边算法）、样品参数（ρ、d_η、Θ，失败时自动二分步长）。
  用割线预测 + 相位对齐；新解偏离预测 >50% 视为“跳支”而拒绝。连续失败 = 解族端点（阈值/分岔），写入 summary。
* **初值**：LG 型 $(r/w_0)^{|m|}e^{-r^2/w_0^2}e^{im\theta}$，用 Rayleigh 商定振幅、在若干宽度中挑残差最小者；
  表面态等非对称情形用“自洽线性模式”初值（`guesses.scf_guess`：求自感应势中的线性模式并组合，表面涡旋需扫描两个偶极模式的权重比）。

## 3. 线性稳定性
* **首选**：全样品稀疏增广系统 + shift-invert Arnoldi（`stability_arnoldi`），沿 $\sigma=0.02+i\omega$ 扫描。几秒/shift，无截断误差。
* **稠密法**（`stability_dense`）：在光束附近截断区域内求全部本征值。**陷阱**：截断半径太小会产生虚假的软模不稳定
  （预实验：圆盘 m=2 涡旋，截断半径 7 → 虚假增长率 0.02；9 → 6e-4；11 → 6e-6；Arnoldi 全样品：1e-12）。只用于小问题或交叉检验。
* 判据：max Re λ > 1e-4 记为线性不稳定；必须配合加噪声传播。线性弱不稳定但传播中有界振荡（非线性饱和）要单独标注。

## 4. 传播
Crank–Nicolson（线性部分，酉）+ Strang 分步（非线性相位），每步一次复 LU 回代 + 一次热传导回代。
能流守恒到 1e-13；空间离散与牛顿完全相同，定态在传播中只有 $O(\Delta\xi^2)$ 偏离（E0a 第 5 项：dz 减半误差降为 1/4）。

## 5. 奇点诊断
* **单位奇点**：小方格四角相位差累加。某边相位差恰为 π（实数场跨节线）时绕数无定义，记 0；实数场直接返回无奇点。
* **混叠陷阱**：4 个角点无法表示 |荷| ≥ 2 的奇点。中心在方格内的正则 m=3 涡旋会被读成“中心 −1 + 4 个 +1 卫星”
  （预实验中一度把这个检测假象误认为网格物理效应，已改正，见单元测试 `test_multicharge_center_not_aliased`）。
  因此：中心半径 1.25h 内不用方格法；中心荷用多点圆周绕数 $W(r)$。
* **亚网格**：三次插值在 $r<h$ 处对 $r^{|m|}$ 型高阶零点（|m|≥3）误差可达 O(1)，$W(0.5h)$ 只有当卫星环半径 ≥ 2h 时可信。
  更小的嬗变核用中心角谐波拟合 $c_l(r)\approx a_lr^{|l|}$ 估计 $r_s=(|a_v|/|a_m|)^{1/(|m|-|v|)}$（`r_s_fit`）。
  报告中给出 `W_profile`（0.5h…3h 的绕数）供判读。
* **C_n 不可约表示权重**：旋转插值后投影。网格只有 C_4v 对称，n=3,5,6 时权重会有 1e-5 量级的偏离。

## 6. 网格假象：必须遵守的约定
笛卡尔网格自身是 C_4 对称的。九点格式把它压到 $O(h^4)$，但高阶涡旋对各向异性“超敏感”（$r_s\propto\varepsilon^s$，s 可小至 1/4）：
* 圆盘对照组中 m=4 的网格诱导分裂随 h 只缓慢减小（预实验 h=0.4→0.15：0.48→0.23）；
* n=5,6 多边形在 ρ=8 时物理各向异性与网格误差同量级，(5,3) 的“嬗变”在旋转检验中不随样品转动 → 是假象；
* 因此：**任何关于嬗变结构的结论都要满足 (i) 卫星环半径 ≥ 2h 或 r_s_fit 在加密网格下收敛；(ii) 通过 E0d 旋转检验；
  (iii) 远大于同 h 下圆盘对照组的假象水平**。n=5,6 的规则改用 E5a 的强加热展示（物理各向异性可调到远大于网格误差）。
